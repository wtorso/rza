# RZA 0.1.0 prerelease

This is the first packaged RZA release. It provides the native compiler, C23
runtime headers, source, tests, benchmarks, and examples. It is a prerelease, not
a stable language or host-ABI compatibility promise. Host ABI version is 4.

## Platforms and requirements

- `rza-0.1.0-linux-x86_64.tar.gz`: Linux x86_64, built on Ubuntu 24.04.
- `rza-0.1.0-windows-x86_64.tar.gz`: Windows x86_64 with `rez3asm.exe`, using
  dynamic Microsoft C runtime components (`VCRUNTIME140.dll` and `dbghelp.dll`).
  A static CRT is not included.
- C3 is not needed to run the packaged compiler.
- A C23 compiler is still required to compile generated C. C3 0.8.5_1 is needed
  only when rebuilding the RZA compiler from source.
- Other operating systems, architectures, static linking, and cryptographic
  signatures are not included in this release.

## Verify and run

Download the archive for your platform and `SHA256SUMS`, then run the following.
`--ignore-missing` skips the other platform's archive in the checksum file:

```sh
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf rza-0.1.0-linux-x86_64.tar.gz
cd rza-0.1.0-linux-x86_64
./rez3asm --version
./rez3asm examples/hello.rza --emit-c -o hello.c
cc -std=c23 -O2 -Wall -Wextra -Werror -I refs hello.c -o hello
./hello
```

Expected program output is `41`. Use the corresponding Windows archive and
`rez3asm.exe` on Windows.

`RELEASE.txt` records the version, full source commit, target, C3 version, and
`RZA_DIRTY=0`. A dirty development archive is not accepted by the release smoke
checks. SHA256 checks file integrity; it is not a cryptographic signature.

## Install for the current user

From the extracted package directory:

```sh
RZA_COMPILER=./rez3asm PREFIX="$HOME/.local" bash install.sh
export PATH="$HOME/.local/bin:$PATH"
```

The installer copies the compiler, `rez3.h`, `rez3ext.h`, and LICENSE. When
compiling generated C after installation, use:

```sh
cc -std=c23 -O2 -I "$HOME/.local/include/rza" hello.c -o hello
```

See `README.md` or `README.ru.md` for language examples, the complete CLI, host C
integration, tests, and current limits.

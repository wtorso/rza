# RESONANCE-3 — спецификация минимальной модели владения

Статус: модель реализована в REZ3-ASM, чекере и C99-runtime. Норма языка —
`SPEC.md`; этот документ описывает неизменяемое ядро: четыре кирпича, шесть
имён, четыре инварианта.

## 0. Происхождение и prior art

- Плекс: Douglas Ross, APT, 1956 — блоки памяти, слова-указатели, заголовки.
- Поколения в ссылках: capability-машины, slotmap/generational arena, ECS.
- Дерево времён жизни: region-based memory, lexical scope, RAII.
- Ближайший родственник: WebAssembly Component Model — явные границы,
  владение и деструкторы ресурсов.
- Предостережение: UNCOL — судьба «универсальных IR». Новая операция должна
  закрывать класс ошибок, а не добавлять возможности ради возможностей.

## 1. Кирпичи (четыре) и имена

| Имя | Кирпич | Тип |
|---|---|---|
| Field | пул | Корневая бессмертная рамка |
| Cavity | рамка | Name = поколение вне арены; Body = смертная арена |
| Resonator | ячейка | Память с размером в арене конкретной рамки |
| Mediator | связь | Указатель, текущий и домашний владельцы, поколения, размер |
| Cascade | шаг | Пересечение границ через проверенные связи |
| Decay | переход | Смерть рамки и её поддерева |

Смешение Name и Body — ошибка модели. Поколение рамки живёт после освобождения
её арены и не даёт старой связи принять новую память за прежнюю.

## 2. Операции (восемь, исчерпывающе)

  enter(parent) -> Frame        — рождение рамки
  leave(f)                      — Decay: gen++, арена мертва, поддерево мертво
  resonator(f, size) -> Cell@f  — ячейка в живой рамке
  mediator(c) -> Link           — выдача прохода владельцем или предком
  read(l) -> Cell | DEAD        — чтение с проверкой жизни и границ
  cascade([l...], out: Cell)    — шаг; DEAD на входе = атомарный abort
  raise(c, f')                  — подъём опоры к строгому предку
  alive?(l) -> bool             — наблюдение статуса связи

`raise` меняет текущего владельца для последующей проверки. Память остаётся
в домашней арене: после её Decay связь мертва и обращение даёт `FAULT`.
Физическое перемещение ячейки модель не скрывает.

## 3. Инварианты

  I1  resonator@F:    F — живая рамка
  I2  mediator(c):    выдаёт владелец c или предок владельца
  I3  cascade:        sync — все Link живы на входе;
                      async — Link и OUT принадлежат Field
  I4  raise:          только вверх по дереву

Проверка идёт одним текстовым проходом. Доступ к предку зависит от глубины
дерева; обход поддерева при Decay линеен по числу его рамок. Дерево выбрано
вместо произвольного графа ради простой механической проверки.

## 4. Стирание

  resonator  → bump-аллокация + обнуление + проверка результата
  read       → проверки владельцев, поколений и границ
  cascade    → проверка связей один раз на входе
  leave      → обход и освобождение поддерева
  mediator   → явные метаданные доступа; размер входит в ABI

В sync-каскаде постоянное смещение проверяется компилятором, поэтому горячий
`memcpy` не повторяет проверки жизни и границ. Вычисляемое смещение требует
runtime-проверки. Нулевая цена безопасности не обещается.

## 5. Три потребителя — один объект

- Человек видит дерево рамок и границы жизни данных.
- Генератор кода получает машинные нарушения I1–I4 вместо неявной дисциплины.
- Компилятор стирает только доказанные проверки; остальные остаются в C99.

Внутри языка мёртвый доступ и выход за ячейку не являются неопределённым
поведением. Хост, написанный на C, обязан соблюдать ABI и не подделывать
медиаторы: граница языка не делает произвольный C безопасным.

## 6. Границы

1. Циклические графы и совладение не входят в дерево модели.
2. Вычислительные ядра и SIMD остаются отдельной задачей.
3. Распределённые связи и async-транспорт не реализованы; `acasc` синхронен.
4. Новая операция без нового класса предотвращаемых ошибок не добавляется.

## 7. Артефакты

  A. Чекер I1–I4 и отрицательные тесты — `rez3asm.c3`, `tests/viol_*.rza`.
  B. Транслятор в C99 — `rez3asm file.rza --emit-c`.
  C. Листинг стирания — `docs/ERASURE.md`, воспроизводится из теста.
  D. Метрика пользы для генерации кода требует отдельного открытого эксперимента.

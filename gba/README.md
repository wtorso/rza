# rza/gba — REZ3-ASM на Game Boy Advance

Экспериментальный путь **.rza → C99 → GBA ROM**. Отдельный бэкенд не нужен:
GBA использует ARM7TDMI, а i64 реализуется компилятором над 32-битными
регистрами. Сборка использует `zig cc` с целью `arm-freestanding-eabi`.

## Конвейер

```sh
cd rza/gba
./build.sh ../tests/fib.rza out/fib.gba
```

Полученный ROM можно открыть в эмуляторе GBA с просмотром памяти EWRAM.

- `crt0.c` — заголовок GBA, `_start`, стек IWRAM, копия `.data` из ROM в
  EWRAM и обнуление `.bss`.
- `harness.c` — небольшая замена libc для stand-alone ROM: `printf`,
  `fprintf`, `exit`, `malloc`, `memset`, `memcpy`.
- `gba.ld` — код в ROM `0x08000000`, данные в EWRAM `0x02002000`.
- `include/` — объявления libc для freestanding-сборки.

## Проверка результата

Лог находится в EWRAM по адресу `0x02000000`, записи имеют тип i64:

- `[0]` — `0x1A5A525A31` после аварийного `exit`;
- `[1..]` — по одному значению на `printf`;
- `probe` записывает `1` для `ALIVE` и `0` для `DEAD`;
- `fprintf` на путях `FAULT`/`ABORT` записывает номер исходной строки;
- `exit` добавляет маркер `0x0DEC0DE000000000 | code`.

Для `fib.gba` запись `[1]` должна быть `0x37 = 55 = F(10)`. Сценарий
вычисления находится в `tests/fib.rza`, а не во внешнем проекте.

## Границы

- Лог ограничен 500 записями i64.
- Нормальный возврат из `main` останавливается в halt-петле без записи magic.
- Стендовый `malloc` не освобождает память: это ограниченный harness для
  проверки переносимости, а не общий runtime для игр.
- Каталог `gba/` не входит в общий прогон `bash run_tests.sh`.
